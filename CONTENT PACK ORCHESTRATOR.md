# AI Content Creation Pack Orchestrator

This pack contains Systems 05, 06, 09, 10, 13, and 14. Its job is to turn one real idea or recording into a repeatable content process without rebuilding the creative rules every time.

## Fast first win

Choose one:

- Set up one short copied edit with System 14 when the user has footage to finish.
- Build one tested style card with System 06.
- Build one source-grounded content map with System 10.

Do that before installing motion tools.

## Route the work

1. Choose System 05 for a conservative pre-edit only, or System 14 for a full editable video. System 05 stays optional and standalone.
2. In System 14, prove setup, review the clean cut and preserve approved manual changes before visual finishing.
3. Use System 06 to define static identity and accuracy rules, and System 09 for approved beats that benefit from explanation or motion.
4. Finish the requested masters in System 14 and verify the editable handoff.
5. Use System 10 to select traceable clips and text derivatives from the appropriate approved source when requested.
6. Use System 13 on everything that ships: titles, hooks, and covers pass its constitution, and prose passes its quality gate. Use the final export transcript for the description and chapters.

Copy `templates/CONTENT ROI TRACKER.md` into `_MY WORK` and record ten real runs. Track setup, run, review, rework, quality, and output counts. Views, leads, and sales belong in the notes only when they can be tied to an actual published item. The pack does not promise them.

## Give your AI this message

```text
Read this orchestrator, READ ME FIRST.md, SETUP GUIDE.md, and the START HERE.md files for Systems 05, 06, 09, 10, 13, and 14. Ask whether I have an idea, script, edited source, or long recording. Recommend the smallest first output: a style card, source-grounded content map, or a short copied edit with System 14. Keep System 05 available for a pre-edit-only request. Name any tool, provider, cost, license, or manual approval required. Use the free or no-generation path unless I approve another route. Keep publication manual. Save approved work under _MY WORK/Content Pack and record the real result in the Content ROI Tracker.
```

System 10's portable mechanics pass controlled synthetic tests. Selection quality still depends on the source, transcript, approval, and human review, so do not claim that it will choose good content from every recording.
