# AI Content Creation Pack Orchestrator

This pack contains Systems 05, 06, 09, 10, and 13. Its job is to turn one real idea or recording into a repeatable content process without rebuilding the creative rules every time.

## Fast first win

Choose one:

- Build one tested style card with System 06.
- Build one source-grounded content map with System 10.

Do that before installing motion tools.

## Route the work

1. Use System 05 when the source first needs a conservative, non-destructive pre-edit.
2. Use System 06 to define the static identity and accuracy rules.
3. Use System 10 to select traceable clips and text derivatives from one source.
4. Use System 09 only for approved beats that benefit from designed explanation or motion.
5. Use System 13 on everything that ships: titles, hooks, and covers pass its constitution, and prose passes its quality gate.

Copy `templates/CONTENT ROI TRACKER.md` into `_MY WORK` and record ten real runs. Track setup, run, review, rework, quality, and output counts. Views, leads, and sales belong in the notes only when they can be tied to an actual published item. The pack does not promise them.

## Give your AI this message

```text
Read this orchestrator, READ ME FIRST.md, SETUP GUIDE.md, and the START HERE.md files for Systems 05, 06, 09, 10, and 13. Ask whether I have an idea, script, edited source, or long recording. Recommend the smallest first output: a style card or source-grounded content map. Name any tool, provider, cost, license, or manual approval required. Use the free or no-generation path unless I approve another route. Keep publication manual. Save approved work under _MY WORK/Content Pack and record the real result in the Content ROI Tracker.
```

System 10's portable mechanics pass controlled synthetic tests. Selection quality still depends on the source, transcript, approval, and human review, so do not claim that it will choose good content from every recording.
