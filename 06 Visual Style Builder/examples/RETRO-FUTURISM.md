# Retro-Futurism Starter Card

This example is based on Payton's Retro-Futurism system.

## Definition

A mid-century view of technology built around one clear visual metaphor, hard-edged geometric color blocks, dark outlines, flat fills, warm-cool contrast, and light vintage print texture.

## Essential rules

- Turn the topic into one visual metaphor.
- Use a limited intentional palette with strong warm-cool contrast.
- Build shapes with flat fills and clear boundaries instead of smooth gradients.
- Use print texture in restrained areas rather than covering the whole image.
- Keep the image readable at thumbnail size.
- Integrate any supplied official logo into an object or surface instead of placing an app tile in a corner.

## Avoid

- smooth modern CGI;
- photorealism;
- rainbow color;
- literal software screenshots;
- several metaphors competing;
- a pasted-looking logo badge.

## Test

Apply the style to a tutorial topic and a commentary topic. The first can feel lighter, while the second can use darker contrast without losing the shared visual identity.
